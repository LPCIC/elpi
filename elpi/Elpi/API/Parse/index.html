Module API.Parse

The parser does not stop at the first syntax error: a declaration with a syntax error is skipped up to the next dot and dropped, and its error is returned. The parser stops after flags.max_errors errors, with a last error that says so; if it is 0 (the default, also when flags is not given) the first error is raised as ParseError.

val program : ?flags:Compile.flags -> elpi:Setup.elpi -> string -> Ast.program * Error.t list * Error.warning list

program file parses a file (and its .sig if it is a .mod). Raises Failure if the file does not exist.
