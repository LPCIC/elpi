Module RawData.Constants

val declare_global_symbol : ?variant:string -> string -> constant

A global symbol declared by hand:

  • list it in the BuiltIn.MLConstants of an OCaml builtins declaration (BuiltIn.declare)
  • be sure the Elpi text of that declaration contains plain symb f : ty (or a pred / func signature), followed by = "variant" if it is not the default variant. The same name and variant give the same constant. Several global symbols can share a name if their variants differ: a variant is the name of the library followed by a dot and a name, e.g. "std.1" or "json.1", so that two libraries cannot collide. Without variant, the default variant: two libraries that declare the same name share the symbol.
