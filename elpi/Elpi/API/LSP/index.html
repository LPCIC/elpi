What the language server (elpi-lsp) needs: the information on a unit, by location, and the accumulate directives of a program

what is at a location of a unit

type info = {
  1. kind : kind;
  2. description : description option;
  3. defined : Ast.Loc.t option;
  4. doc : Ast.Loc.t option;
  5. body : Ast.Loc.t option;
  6. declaration : bool;
  7. occurrences : Ast.Loc.t list;
}
val pp_info : Stdlib.Format.formatter -> info -> unit
val hover : ?base:Compile.program -> Compile.scoped_program -> Compile.compilation_unit -> info IntervalTree.t

hover ?base sp u is the information on the unit u, by location: the terms and the symbols of its rules, CHR rules and macros, and the type expressions of the declarations of its scoped program sp. base is the program u extends, for the doc and the body of the constants declared there.

val accumulated : Ast.program -> (Ast.Loc.t * string list) list

accumulated p is the list of the accumulate directives of p (not of the files it accumulates): the location of each one, and the files that it accumulates, directly or not, by the names that the locations of their contents have.
