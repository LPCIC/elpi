Module API.BuiltIn

Setup.init takes a list of declarations of data types and predicates, plus some doc and eventually some Elpi code. All this constitutes the "prelude", that is what is avaiable to an Elpi program

type doc_spec =
  1. | DocAbove
  2. | DocNext

Where to print the documentation. For the running example DocAbove * generates * % div N M D R division of N by M gives D with reminder R * builtin func div int, int -> int, int. * while DocNext generates * builtin func div % division of N by M gives D with reminder R * int, % N * int % M * -> * int, % D * int. % R * The latter format it is useful to give longer doc for each argument.

type declaration =
  1. | MLCode of BuiltInPredicate.t * doc_spec
  2. | MLData : 'a Conversion.t -> declaration
  3. | MLDataC : ('a, 'h, 'c) ContextualConversion.t -> declaration
  4. | MLConstants of Data.constant list
  5. | MLCalc of calc_operations
  6. | LPDoc of string
  7. | LPCode of string
val declare : file_name:string -> declaration list -> Setup.builtins

An OCaml builtins declaration, what is passed to Setup.init. It can also be called after Setup.init (e.g. by a plugin linked later, with its global symbols, data types and calc operations): a program then accumulates it with Compile.scope_builtins, Compile.unit and Compile.extend on its base. Such a declaration must not declare state components or quotations, see State.declare_component and Quotation

val of_file : file_name:string -> Setup.builtins

Retrieves the builtins associated to file_name (and previosuly declared with declare). Raises Not_found

val document_fmt : Stdlib.Format.formatter -> Setup.builtins -> unit
