elpi

This is the API reference for the elpi OCaml package.

  • Public API
  • Internal libraries

Public API

Elpi (library elpi, findlib -package elpi) is the only public, supported entry point: everything a host application needs to embed the interpreter, drive it, and extend it with custom builtins, data types and quotations lives under this one module (see the Embedding and extending chapter of the user manual for a guided tour).

Internal libraries

The rest of this package's libraries are Elpi's own implementation, split into separate dune libraries for internal build reasons: Elpi_compiler, Elpi_lexer_config, Elpi_parser, Elpi_runtime, Elpi_trace_atd, Trace_ppx, Trace_ppx_runtime and Elpi_util. They are documented here only because they are part of the same opam package; they are not a supported API, carry no compatibility guarantees across releases, and a host application should never depend on them directly.
